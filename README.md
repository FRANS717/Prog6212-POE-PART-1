# System Overview
RaceDay is an event management platform for South African road running, walking, and cycling events. It connects Event Organisers with Participants.
Organisers can create events, manage categories, view enrolments, and capture results.
Participants can browse events, enrol, view their enrolments, and track their results.

# Planning Documents
1. ERD - Located in /docs/erd.png
Shows all database entities, their attributes, primary keys, foreign keys, and relationships with cardinality.
2. API Endpoint Plan - Located in /docs/endpoint-plan.md
Lists all RESTful endpoints with HTTP method, route, description, role required, request body, and expected response.
3. SQL Script - Located in /docs/RaceDay-Schema.sql
Creates the full database schema with all tables, constraints, and seed data.
